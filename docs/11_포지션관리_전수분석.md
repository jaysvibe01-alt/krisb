## 1. 시장 유형별 청산 매트릭스

핵심 발견: **두 트레이더 모두 시장 유형을 5~6개로 분류하고, 청산 전략을 유형별로 다르게 적용한다.** 봇 v1.15 의 "모든 자리 = TP1 전량 청산"은 두 사람 누구의 가르침과도 일치하지 않는다.

| 시장 유형 | Kris 발언 (출처) | Murph 발언 (출처) | 권장 청산 |
|---|---|---|---|
| **A. 마지막 장대 (climactic)** | "걸릴 자리가 너무 많다 → 짧게만 트라이" (`KRIS_FULL_LECTURE_ANALYSIS.md:595-609`) — 한 번에 크게 먹기 어려운 자리 인식 | "1차 패닉보다 더 안전한 후보는 이후 캔들 짧아지는 구간" (`Murph_진바닥잡기_화면타점검토.md:58-62`) — 마지막 장대 직후 진입은 공격적 | **반털 (50% 익절) + 잔여는 캔들 짧아지는 다음 구간까지 대기.** 단독 들고 가는 자리 아님 |
| **B. 첫 장대 후 대기** | "깨져야 깨지는겁니다. 아니면 바닥에서 숏이 될수 있으니" (`KRIS_FULL_LECTURE_ANALYSIS.md:46-47, 240`) — 컨펌 전 진입 금지 | "첫 장대 자체를 바로 잡지 않는다. 1분봉/5분봉에서 제자리 거래량, 도지/짧은 캔들, 거래량 감소 재하락을 기다린다" (`Murph_통합전략_v1.md:64-72`) | **두 번째 도지 확인 후 진입 → TP1 1R 부분 익절, TP2 매물대까지.** 진입 자체가 늦으므로 익절도 보수적 |
| **C. 느린 추세 (slow grind)** | "질질 움직임 = 낮은 품질 진입. 손절/익절 기준 지저분해진다" (`KRIS_FULL_LECTURE_ANALYSIS.md:140-150, KRIS_SCALPING_RULEBOOK.md:163-171`) | "느린 매수는 길게 가져가되, 채널 이탈은 즉시 무효" (`Murph_진바닥잡기_화면타점검토.md:105`, 3강 08:52); "진입도 천천히, 청산도 천천히 판단" (`Murph_통합전략_v1.md:86`) | **분할 익절 (수평마다 일부씩) + Trail Stop.** Kris 식 "수평 닿을때마다 익절" 적용 |
| **D. 대폭락 (capitulation)** | "1분봉 단위 10% 이상 변동 가능 → 진입보다 청산과 리스크 축소가 중요" (`KRIS_LAB_SCALPING_LECTURE_ANALYSIS.md:73-75`); "짧은 구간 익절" (`:84`) | "**바닥에 딱 들어가서 짧게 먹고 바로 나오는 스캘프 성격**" (`Murph_진바닥잡기_화면타점검토.md:114`); "바닥에 딱 들어갔다가 올라가면 바로 이 300불 먹고 바로 나가야 됩니다" (4강 06:23, `Murph_진바닥잡기_전체분석.md:167`); "오래 들고 가는 자리가 아님" (`화면타점검토.md:122`) | **반대 — 단타 스캘프 (TP1 전량 청산).** 사용자가 처음 가정한 "반익절 후 장기"는 두 자료 모두에서 부정됨. 대폭락 직후는 짧고 빠른 반등만 잡고 바로 나간다 |
| **E. 두 번째 바닥 (더블바텀)** | "두 번째는 가능하지만 짧게" (`KRIS_FULL_LECTURE_ANALYSIS.md:1221`); "두 번째 롱 트라이는 더 짧아야 한다" (`:1189`) | "두 번째 바닥은 첫 바닥보다 확인 정보가 많다" (`Murph_통합전략_v1.md:130`); "머프식 바닥잡기에서 가장 선호되는 구조" (`:126`) | **분할 익절 — TP1 50% (1R), TP2 30% (피보 1.236), 잔여 20% Trail.** 두 사람이 가장 동의하는 구조 |
| **F. 추세 강한 돌파** | "장대로 빠르게 도착 → 반응 선명 → 익절까지 거리 있음" (`KRIS_SCALPING_RULEBOOK.md:156-161`) — 좋은 움직임에서는 거리 있게 익절 | "장조이풀 양봉이 떴어요 큰 더 들고 가져 100% 전부" (3강 20:08, `차트분석심화_전체분석.md:106`); "평균 거래량 대비 3배 정도 뜨는 거래량이 나오면 들고" (3강 22:59, `:108`) | **장기 보유 (분할 청산) — TP1 30% (1R), TP2 30% (매물대), TP3 40% Trail.** 강한 양봉 + 거래량 3배 동반 시 들고 갈 수 있는 유일한 시장 유형 |

**핵심 통찰**: 사용자가 D 자리를 "반익절 후 장기"로 가정했지만, **원본 자료에서는 정반대로 명시**되어 있다. D 자리야말로 가장 짧게 끊어야 한다 (Murph 4강 06:23 "300불 먹고 바로 나가야 됩니다"). 장기 보유는 오히려 **F (추세 강한 돌파)** 또는 **E (두 번째 바닥) + 강한 컨플루언스** 자리에서만 정당화된다.

### 2.3 재진입 룰 (Kris 본인 발언)

직접 룰화된 재진입 발언은 명시적으로 없지만, 행동 패턴은 다음과 같이 정리된다:

```text
수평 닿음 → 반털 (50%)
  → 수평 지지/저항 확인 (몸통 마감 기준)
    → 지지 성공 → 잔여 50% 들고 다음 수평까지 보유
    → 지지 실패 (몸통 이탈) → 다털 (잔여 50% 청산)
      → 깨진 수평이 반대 역할로 리테스트되는지 확인 (SR flip)
        → 리테스트 성공 시 반대 방향 신규 진입 가능
```

이 패턴은 `KRIS_FULL_LECTURE_ANALYSIS.md:619-637` "프레임 전환 능력" 섹션에 명시: "숏 시나리오가 깨지면 롱/반등 시나리오로 전환한다... 스캘핑은 의견 싸움이 아니라 조건 전환이다."

### 2.4 Murph 측 대응 개념

Murph 자료에는 "반털/다털"이라는 용어 자체는 없으나, **분할 청산** 개념은 동일하게 존재:

- "**분할 매도를 한다고 했잖아요 지금은 발목 매도를 분할 매도 로 하지만 그때 같은 경우에는 이렇게 나눠서 부담이 매도로 했어요 여기에다 매도를 한 다음에 반을 외도를 하고**" (Murph 5강 07:52, `차트분석심화_전체분석.md:170`)
- "1R 도달 후 일부 청산. 2R 도달 후 나머지 청산. 구조상 목표가 가까우면 전량 청산" (`Murph_고도화전략_구현플랜_v1.md:231-235`)

**일치점**: 두 사람 모두 "구조상 목표가 가까우면 전량, 거리가 있으면 분할" 원칙은 같다.

### 3.3 두 트레이더 합의 vs 불일치

**합의점**:
1. 시장 유형별 청산 차별화 (단일 모델 거부)
2. MTF 컨플루언스 강할수록 길게 보유
3. 돌파 직후 추격 금지 + 리테스트 후 진입
4. 첫 번째 터치는 신선, 세 번째는 위험
5. 거래량 + 캔들 + 위치 결합 없이 단독 진입 금지

## 5. 추천 1-2 모델 + 코드 가이드

### 5.1 추천 1순위: **모델 3 (E 자리 = 더블바텀 분할)**

**근거**: 두 트레이더 모두 최선호 자리 + 봇에 이미 `detect_double_bottom` 검출 함수 존재 (`09_Murph_통합_검토.md:147` 참조) + 거래량 감소 재하락 검출 가능 + 분할 청산이 두 트레이더 청산법(반털/1R 분할)과 100% 정합.

**구현 코드 가이드** (의사코드):

```python
# krtky_alert_bot.py 청산 로직 확장
def determine_exit_plan(entry_signal, market_context):
    """
    시장 유형별 청산 계획 분기.
    기본은 v1.15 의 TP1 전량 유지, 더블바텀만 분할.
    """
    if (entry_signal.has_double_bottom 
        and entry_signal.has_volume_decay  # 재하락 거래량 감소
        and market_context.market_type in ("E_double_bottom", None)):
        # Model 3: 분할 청산
        return ExitPlan(
            tp1_pct=0.50,            # 1R 도달 시 50% 청산 (반털)
            tp1_target_r=1.0,
            tp2_pct=0.30,            # 크보나치 1.236 (피보 확장) 도달 시 30%
            tp2_target_fib=1.236,
            trail_pct=0.20,          # 잔여 20%는 trailing stop
            trail_atr_mult=1.5,
            invalidation="prev_low_break"  # 앞전 저점 이탈 시 무효
        )
    else:
        # 기본: v1.15 TP1 전량
        return ExitPlan.default_tp1_full()
```

**예상 효과 측정 방법**:
1. 기존 백테스트 데이터에서 `detect_double_bottom == True AND volume_decay == True` 거래만 필터 (예상 표본 ~200건/년)
2. 동일 자리에 대해 모델 1 (TP1 전량) vs 모델 3 (분할) EV 비교
3. EV 동등 또는 +1% 이상이면 채택 (분할은 trailing 으로 큰 추세 캡처 가능성 추가)

## 6. 종합 결론

### 6.1 핵심 발견 3가지

1. **사용자 가정 (D = 반익절 + 장기) 은 원본 자료와 반대**. Murph 4강 06:23, `진바닥잡기_화면타점검토.md:114, 122` 모두 D 는 "짧게 먹고 바로 나가는 스캘프 성격" 으로 명시. 장기 보유는 오히려 **F (추세 강한 돌파)** 또는 **E (두 번째 바닥) + 강한 컨플루언스** 자리에서만 정당화됨.

2. **봇 v1.15 의 "TP1 전량" 단일 모델은 Kris/Murph 누구의 가르침과도 일치하지 않음**. 둘 다 "분할 청산"을 기본으로 함. Kris = "반털/다털 + 수평마다 익절", Murph = "1R 부분 / 2R 잔여 / 구조 가까우면 전량". 다만 **백테스트 +35,000% 자체는 부정 불가** — 단일 모델이 봇에 적합한 이유는 알림봇이 빈도와 단순성을 요구하기 때문 (`10_Murph_D_부스트_비판검토.md:11-13` 합리적 부스트 논거 참조).

3. **두 트레이더 합의가 가장 강한 자리 = E (두 번째 바닥)**. 이 자리에 한해 분할 청산 (모델 3) 을 시범 적용하는 것이 위험 최소, 효과 검증 용이.

### 6.2 즉시 적용 1순위 권장

**모델 2 (D 자리 보유 시간 cap)** 부터 적용. 이유:
- 코드 변경 최소 (`max_hold_bars` 한 줄)
- 원본 자료 정합성 100%
- 손실 회피 효과 (큰 wick 후 추가 패닉 회피)
- EV 측정 용이 (D 자리 70건만 비교)

이후 백테스트 결과 + EV CI 측정 후 **모델 3 (더블바텀 분할)** 단계적 도입.

### 6.3 즉시 적용 금지

- **모델 6 (시장 유형 자동 분류)** — 6개 유형 분류 오류 시 EV 분포 왜곡. 현재 봇은 D/A 만 부스트로 분류하므로 6개 분류기를 추가 검증 없이 도입하는 것은 위험.
- **F 자리 (장기 분할) 모델 4** — Murph 가 "들고 가는 자리" 라고 한 인용 (3강 22:59) 은 STT 오인식 가능성 있음 (원본 자막 "조이풀 양봉" 등 표현이 부자연스러움). 원본 영상 재확인 후 적용 검토.
