## 1. 부스트 vs 게이트 권장

현재 봇은 D를 **부스트(Level 격상)** 로만 쓴다. 즉 Long/Short 진입 게이트는 기존 5단(RSI 30/70 + 장대 + 거래량 + 컨펌봉 + 다음봉 꼬리) 그대로 통과시키고, 시장 유형이 D면 `level = max(level, 3)`로 알림 강도만 ★3으로 올린다. 진입 자체는 D가 아니어도 발생한다. 게이트로 바꾸면 D 자리에서만 진입을 허용하고 나머지 2,841건은 차단해야 한다. 산술 비교는 명확하다: 부스트 = 2,911건 × 평균 +0.115R = +335R/년에 D 70건의 추가 효과 +0.20R × 70 = +14R 가산 → **총 +349R**. 게이트 = 70건 × +0.311R = **+21.77R/년**. R 총합 기준 부스트가 16배 우월하다.

게이트가 매력적으로 보이는 이유는 단일 거래 평균 R(0.311 vs 0.115)이지 시스템 R 총합이 아니다. 알림봇은 거래 빈도가 의미 있어야 사용자가 "켜둔 의미"를 느낀다. 1년에 70건(주당 1.3건)이면 사용자는 봇 알림을 무시하다가 D가 떠도 놓친다. 또한 D 70건의 표본 분산이 측정되지 않아(아래 §3) 게이트화 시 실제 EV가 +0.311R에서 +0.1R 근처로 회귀할 위험도 크다. **현재의 부스트 구조 = 합리적 선택.** 다만 부스트만으로는 D의 진가를 거의 못 살리는 게 또 사실이다(2,841건의 평균 EV가 D 추가분을 희석). 절충안으로 **"D + 다른 강력 부스트 1개 이상 동반 시에만 추가 격상"** 같은 조건부 부스트가 합리적이다.

## 2. D 정의 위험성 — look-ahead 의심?

D 정의는 단순하다: `last_range > avg(직전 20봉 range) × 3`. 15분봉 기준 BTC 평균 range가 ATR 약 0.4% 대라면 D 트리거 봉은 1.2% 이상 wick, 알트는 3-6%급 wick이다. 문제는 **"큰 wick = 바닥 = Long 좋다"라는 인과가 데이터에 없다**는 점이다. 큰 wick은 ①진짜 패닉셀 후 V자 반등의 출발점일 수도, ②추가 하락 중간의 일시 반등(데드캣) 후 더 깊은 패닉의 시작점일 수도 있다. 백테스트 EV +0.20R는 두 경우의 가중평균 결과인데, MAX_HOLD_BARS(보통 16-32봉)를 다 채워서 TP/SL 중 어디 닿았는지를 본 것이라 **선택 편향이 거의 없다.** Look-ahead 의심은 약하다(미래봉을 D 판정에 쓰지 않음).

다만 **시뮬레이션 편향**은 남는다. ①D는 발생률 2.4%로 희소 → 표본이 변동성 폭발 국면(2024년 8월 캐리트레이드 청산, 2025년 1월 BTC 110k→90k 등) 같은 특정 매크로 이벤트에 몰려 있을 가능성이 크다. ②`backtest_realistic_pnl.simulate_trade`는 ATR×1.5 SL이라 D 자리는 SL이 비정상적으로 넓게(평소 0.8% 대신 4-5%) 잡힌다. 절대 손실은 큰데 R 단위로는 좋아 보이는 착시가 있다. ③진입가는 "다음봉 꼬리 매수존"인데 D 직후 다음봉도 wick이 크면 슬리피지가 SL을 침해할 수 있다. 백테스트가 이 부분을 보수적으로 모델링했는지 확인 없이 EV +0.20R를 액면가로 받으면 위험하다. **결론: look-ahead는 아니지만, 표본의 매크로 의존성 + 넓은 SL의 R 정규화 효과는 의심해야 한다.**

## 3. 70건 표본 신뢰성

표본 크기 N=70은 통계적으로 약하다. Win 75.7%라면 표준오차 SE = √(0.757 × 0.243 / 70) ≈ 5.1%p, 95% 신뢰구간 65.5%~85.9%다. avg R +0.311R도 표준편차 측정 없이 점추정으로만 보고됐는데, R 분포가 비대칭(승은 1-3R, 패는 -1R 고정 부근)이라 표본분산이 크다. R 표준편차를 1.2R로 가정하면 N=70의 SE = 1.2/√70 ≈ 0.143R, 95% CI는 +0.025R ~ +0.597R. 즉 진짜 EV가 0.025R(거의 무효)일 가능성과 0.6R(매우 강력)일 가능성이 동시에 살아 있다.

또 다른 신뢰성 약점: D 발생률 2.4%는 매크로 국면 의존이라 **2024-25 데이터 1년 = 1개 표본**으로 봐도 무방하다(서로 독립 사건이 아님). 2022 LUNA, FTX 같은 다른 폭락 국면 데이터로 outsample 검증이 없다. 권장 보완 ①워크포워드 5분할(이미 `backtest_walkforward.py` 존재) 적용 ②부트스트랩 1,000회로 EV 분포 측정 ③D 자리만 따로 차트 70장 시각 검증해 "진짜 패닉셀 바닥 vs 중간 wick" 비율 카운트. **현재 +0.20R 수치를 "검증된 부스트"라고 코드 주석에 박는 건 과신이다.** 봇 코드의 `EV +0.20R N=70`는 "현재까지 추정치, CI 넓음"으로 표기를 바꿔야 한다.

## 4. A 경고 라벨 효용

A_last_climactic은 EV -0.12R(타입 외 대비)이 측정됐는데 진입은 차단하지 않고 `⚠️ 마지막 장대형 (Murph A 참고, EV -0.12R 주의)` 라벨만 붙인다. 의도는 "사용자가 차트 보고 의식적 판단"이지만, 실제로는 **이중적 신호 노이즈**다. 봇이 이미 RSI + 장대 + 거래량 + 컨펌 + 꼬리 5단 게이트를 통과시켜 알림을 보냈다는 건 "진입할만한 자리"라고 판정한 것. 거기에 ⚠️ 경고를 붙이면 사용자는 ①봇을 신뢰해 진입(라벨 무시) ②경고 보고 패스(알림 무용) 둘 중 하나다. 후자라면 진입 자체를 차단(SKIP)하는 게 봇의 일관성에 맞다.

A 라벨이 의미를 가지려면 "A + 다른 부스트" 조합 EV를 측정해 조건부 효용을 보여줘야 한다. 가설: A 단독은 -0.12R지만 "A + 다이버전스" 또는 "A + 4H RSI 극단" 조합에서는 +R로 뒤집힐 수 있다(climactic이 진짜 바닥인 경우 = MTF 컨플루언스 동반). 이 교차 EV 측정이 없는 현재 상태에서 A 라벨은 **사용자 인지 부담만 늘리고 실제 행동 변경엔 기여 X**. 권장: ①A 단독은 라벨 제거 또는 ②A + (다이버 OR 4H RSI OR PREMIUM) 조합 시에만 라벨 유지 + 진입 OK, ③A 단독이면 ★ 격상 차단(level cap = 1)로 강도라도 낮추는 게 합리적이다. 현재의 "라벨만 붙이고 끝"은 최악의 절충이다.

## 6. 종합 권장 — 즉시 변경 사항 1개

**즉시 변경 1순위: D 부스트 주석 + level 정책 두 가지 동시 정정.**

```python
# 현재 (krtky_alert_bot.py:1675-1677)
if market_type == "D_capitulation":
    extras.append("⚡ 대폭락 자리 (Murph D 시장유형, EV +0.20R N=70)")
    level = max(level, 3)

# 변경 권장
if market_type == "D_capitulation":
    # 표본 N=70 (점추정, 95% CI 미측정). 다른 강력 부스트 동반 시에만 ★3.
    extras.append("⚡ 대폭락 자리 (Murph D, 추정 EV +0.20R N=70 ※표본 적음)")
    # D 단독이면 ★2, D + (다이버/4H RSI/PREMIUM) 동반 시 ★3
    boost_count_strong = sum([
        "다이버전스" in s for s in extras
    ]) + sum([
        "4H RSI" in s for s in extras
    ]) + sum([
        "PREMIUM" in s for s in extras
    ])
    level = max(level, 3 if boost_count_strong >= 1 else 2)
```

이유 3가지:
1. **표본 신뢰성 문제 명시화** — `EV +0.20R N=70`만 적어두면 코드 읽는 사람이 액면가로 받는다. "표본 적음" 한 마디로 §3의 통계적 약점을 코드 안에 박는다.
2. **단독 D 격상 자제** — D 단독으로 ★3 격상은 §1의 "부스트가 합리적"이라는 결론과 §3의 "표본 약함"이 충돌하는 지점. 절충안으로 D 단독은 ★2, MTF 컨플루언스(다이버 / 4H RSI / PREMIUM 중 1개 이상)와 동반될 때만 ★3으로 올린다. 백테스트가 D + 다른 부스트 조합 EV를 측정 안 했지만 **공통 부스트들은 독립적으로 모두 +EV가 검증되어 있으므로** 동반 시 D의 실제 EV가 점추정보다 위쪽 CI(~+0.6R)에 가까울 가능성이 높다는 베이지안 추론이 가능하다.
3. **A 라벨 처리는 별도** — §4의 A 라벨 효용 의심은 별도 백테스트(A + 부스트 교차 EV)가 필요해 즉시 변경 대상이 아니다. 우선 D 정정만 적용하고, A는 다음 사이클에서 처리.

**부가 변경(선택):** 알림 본문에 `★3 (D + 4H RSI 컨플루언스, EV 합 +0.25R 추정)`처럼 Level 산출 근거 1줄 명시. §5의 정보 과부하 완화 첫 단추.
