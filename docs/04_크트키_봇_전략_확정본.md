## 1. 진입 룰 — 크트키 (15분봉 기준)

### 1.1 기본 4원칙 (PPT 표지)

```
① 15분봉
② 장대 캔들  (body/range ≥ 60% AND body ≥ ATR)
③ 거래량    (절대 임계 OR 거래량 SMA × 2)
④ RSI 극단  (oversold ≤ 30 / overbought ≥ 70)
+ 양봉/음봉 컨펌 캔들 (Pre-Alert)
+ 다음 캔들 밑꼬리(롱) / 윗꼬리(숏) 진입 (Entry)
```

### 1.2 봇 상태 머신

```
IDLE
  └─ ④ 충족 시 → PRE_ALERT [1]  (사전 알림 발사, 1회 한정 armed)
        └─ 다음 봉이 반대색 장대캔들로 컨펌
              └─ ENTRY [Level 2~4]  (진입 신호 + 익절·SL 동봉)
        └─ 8봉 안 컨펌 없음 → TIMEOUT (alarm cancel)
        └─ RSI 가 임계 ± 5 회복 → armed 해제
```

- `PRE_ALERT_TIMEOUT_BARS = 8` (백테스트 최적 — 4봉은 가뭄, 12봉은 무의미 알림 과다)
- 한 추세에 PRE_ALERT 1회 한정 (`last_long_armed` / `last_short_armed`)

### 1.3 매수/매도존 (M2 — 백테스트 1위)

| 방향 | 진입 가격대 |
|---|---|
| Long  | [컨펌봉 low, 컨펌봉 close] |
| Short | [컨펌봉 close, 컨펌봉 high] |

### 1.4 부스트 — Level 상승 (Pre-Alert → Entry 진입 신호 강도)

진입 조건은 4원칙이지만, 다음 보조 시그널이 동시에 발생하면 Level 2~4 로 격상되어 알림 강조도 높아진다:

## 3. 익절 룰 — 크보나치 (자동 계산, 알림 동봉)

### 3.1 크보나치 비표준 비율 (Kris PPT 슬라이드 2)

```
0  /  0.764  /  1.0  /  1.236  /  2.0  /  2.26
```

표준 피보(0.236/0.382/0.5/0.618/0.786/1.272/1.618/2.618) 와 다른 Kris 고유 정의.

- `0.764` = 되돌림 (진입 자리 식별용)
- `1.0` = 1:1 자리 (swing 정점에서 같은 폭 확장)
- `1.236 / 2.0 / 2.26` = 확장 (익절용)

### 3.2 익절 타겟 4단계 (`compute_take_profit_targets`)

15m swing(직전 50봉의 max high / min low) 기준으로 자동 계산:

| 단계 | 타겟 | 계산식 (Long) | 출처 |
|---|---|---|---|
| **TP1** | 크보나치 1.236 | swing_low + 1.236 × span | 슬라이드 19 |
| **TP2** | 1:1 자리 | swing_high + span | 슬라이드 9 |
| **TP3** | 크보나치 2.0 | swing_low + 2.0 × span | 슬라이드 39 |
| **TP4** | 크보나치 2.26 | swing_low + 2.26 × span | 슬라이드 2 |
| (옵션) | 일봉 4분할 0.5 (mid) | (일봉_high + 일봉_low) / 2 | 텔레그램 03:11 |

- 일봉 4분할 0.5 는 swing 폭 ≥ 일봉 ATR × 1.5 일 때만 추가
- 진입가 ±0.3% 안의 자리는 즉시 닿으므로 자동 제외
- 진입가에서 가까운 순으로 정렬해서 알림 메시지에 동봉

### 3.3 분할 청산 운용 (사용자 수동)

봇은 알림만 보내고, 거래소에서 사용자가 직접:

```

TP2 (1:1)    30% 청산
TP3/4         20% 트레일링
```

## 6. 1년 기대수익 (자본 대비)

### 6.1 R 단위 → 실제 % 환산

R 단위는 **레버리지 중립적** — 거래당 자본 손실율을 R 로 정규화. 실제 수익은:

| 시나리오 | SL시 자본손실 | 연수익(보수) | 연수익(tiered) | 예상 MaxDD |
|---|---|---|---|---|
| 1배 (현물식) | -0.7% | +11.5% | +94% | 3.5% |
| 5배 × 자본50% | -1.75% | +29% | +236% | 8.8% |
| **10배 × 자본50% (Kris표준)** | **-3.5%** | **+58%** | **+472%** | 17.5% |
| 20배 × 자본50% (공격) | -7.0% | +115% | +944% | 35% ⚠️ |

### 6.2 현실 권장 (Slippage 0.8 배수 반영)

- **5배 × 자본 50% (보수형)** : 연 +23% ~ +189%, MaxDD ~9%
- **10배 × 자본 50% (Kris표준)** : 연 +46% ~ +378%, MaxDD ~18%
- 합리적 중간값 기대: **연 +100~200%**

> ⚠️ 20배 이상은 비추 — 연속 SL 5회면 자본 -35% 드로다운 가능
